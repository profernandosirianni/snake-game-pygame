#  Snake Game em Pygame

Jogo da Cobrinha desenvolvido em Python com a biblioteca Pygame.

#  Como executar o projeto

1. Clone ou extraia o repositorio em sua maquina.
2. Instale as dependencias executando:
   ```bash
   pip install -r requirements.txt
   ```
3. Execute o jogo com o comando:
   ```bash
   python main.py
   ```

# Controles
* **Setas do teclado**: Controlam a direcao da cobrinha.
